# Third-Party Attributions & Open-Source Acknowledgments

Caesium is developed as an independent client-side rendering engine for Minecraft 1.21.11, licensed under the MIT License.

We gratefully acknowledge the pioneering work and architectural research from the open-source Minecraft performance and graphics community:

- **Sodium & CaffeineMC** (JellySquid / IMS / CaffeineMC): Inspiration for modern chunk pipeline architecture, SIMD vectorization concepts, and data-oriented rendering techniques.
- **VulkanMod** (xCollateral): Architectural reference for Vulkan pipeline setup, descriptor management, and SPIR-V compilation under LWJGL.
- **ImmediatelyFast** (RaphiMC): Concepts for batched UI, text, and decal rendering optimizations.
- **Lithium & FerriteCore** (JellySquid / malte0811): Physics, memory reduction, and state-palette memory layout research.
- **Fabric Project**: For the Fabric Loader and Fabric API modding toolchain.
- **LWJGL (Lightweight Java Game Library)**: Native bindings for OpenGL, Vulkan, and GLFW.
