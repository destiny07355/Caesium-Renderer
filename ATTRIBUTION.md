# Third-Party Attributions & Open-Source Acknowledgements

Caesium is an independent client-side performance and rendering project for Minecraft 1.21.11 and is licensed under the MIT License.

## Acknowledgements

The project has been informed by work across the open-source Minecraft performance and graphics community, including:

- **Sodium / CaffeineMC** — modern chunk rendering, data-oriented rendering, and performance engineering research.
- **VulkanMod / xCollateral** — alternative Minecraft rendering backend and GPU pipeline research.
- **ImmediatelyFast / RaphiMC** — batching and client rendering optimization techniques.
- **Lithium** — general Minecraft performance engineering and profiling practices.
- **FerriteCore** — memory reduction techniques for Minecraft.
- **Fabric Project** — Fabric Loader, Fabric API, mappings, and the surrounding modding toolchain.
- **LWJGL** — Java bindings used by Minecraft for native graphics and windowing APIs.

Acknowledgement does not imply that Caesium contains source code from these projects. Any directly reused or adapted third-party code must retain the license and attribution required by its original project.
